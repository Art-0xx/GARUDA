# urlget

## file-read

```bash
urlget - /path/to/input-file
```
_This is part of `gettext` and usually not in `PATH`, e.g., on Arch it can be found at `/usr/lib/gettext/urlget`._
**Contexts:** sudo, suid, unprivileged
