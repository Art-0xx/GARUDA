# bee

## inherit

```bash
bee eval '...'
```
_This allows to run PHP code (`...`).

This must be excuted from the Backdrop CMS root directory (e.g. `/var/www/html`), alternatively use the `--root` option._
**Contexts:** sudo, suid, unprivileged
