# Systeminfo (`S0096`)

[Systeminfo](https://attack.mitre.org/software/S0096) is a Windows utility that can be used to gather detailed information about a computer. [^fn1]



# Techniques Used

## System Information Discovery

[Systeminfo](https://attack.mitre.org/software/S0096) can be used to gather information about the operating system.[\[TechNet Systeminfo\]](https://technet.microsoft.com/en-us/library/bb491007.aspx)
