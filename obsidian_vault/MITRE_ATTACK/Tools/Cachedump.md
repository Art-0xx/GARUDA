# Cachedump (`S0119`)

[Cachedump](https://attack.mitre.org/software/S0119) is a publicly-available tool that program extracts cached password hashes from a system’s registry. [^fn1]



# Platform(s)

- Windows

# Techniques Used

## Cached Domain Credentials

[Cachedump](https://attack.mitre.org/software/S0119) can extract cached password hashes from cache entry information.[\[Mandiant APT1\]](https://www.fireeye.com/content/dam/fireeye-www/services/pdfs/mandiant-apt1-report.pdf)
