# SDelete (`S0195`)

[SDelete](https://attack.mitre.org/software/S0195) is an application that securely deletes data in a way that makes it unrecoverable. It is part of the Microsoft Sysinternals suite of tools. [^fn2]



# Platform(s)

- Windows
