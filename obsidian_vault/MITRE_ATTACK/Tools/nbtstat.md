# nbtstat (`S0102`)

[nbtstat](https://attack.mitre.org/software/S0102) is a utility used to troubleshoot NetBIOS name resolution. [^fn1]



# Techniques Used

## System Network Configuration Discovery

[nbtstat](https://attack.mitre.org/software/S0102) can be used to discover local NetBIOS domain names.

- *Technique:* [[../Techniques/System Network Configuration Discovery (T1016)|System Network Configuration Discovery]]

## System Network Connections Discovery

[nbtstat](https://attack.mitre.org/software/S0102) can be used to discover current NetBIOS sessions.

- *Technique:* [[../Techniques/System Network Connections Discovery (T1049)|System Network Connections Discovery]]
