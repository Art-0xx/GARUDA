# Ping (`S0097`)

[Ping](https://attack.mitre.org/software/S0097) is an operating system utility commonly used to troubleshoot and verify network connections. [^fn1]



# Techniques Used

## Remote System Discovery

[Ping](https://attack.mitre.org/software/S0097) can be used to identify remote systems within a network.[\[TechNet Ping\]](https://technet.microsoft.com/en-us/library/bb490968.aspx)
