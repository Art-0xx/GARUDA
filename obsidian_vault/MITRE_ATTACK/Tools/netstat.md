# netstat (`S0104`)

[netstat](https://attack.mitre.org/software/S0104) is an operating system utility that displays active TCP connections, listening ports, and network statistics. [^fn1]



# Techniques Used

## System Network Connections Discovery

[netstat](https://attack.mitre.org/software/S0104) can be used to enumerate local network connections, including active TCP connections and other network statistics.[\[TechNet Netstat\]](https://technet.microsoft.com/en-us/library/bb490947.aspx)
