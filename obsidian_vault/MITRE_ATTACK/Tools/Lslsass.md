# Lslsass (`S0121`)

[Lslsass](https://attack.mitre.org/software/S0121) is a publicly-available tool that can dump active logon session password hashes from the lsass process. [^fn1]



# Platform(s)

- Windows

# Techniques Used

## LSASS Memory

[Lslsass](https://attack.mitre.org/software/S0121) can dump active logon session password hashes from the lsass process.[\[Mandiant APT1\]](https://www.fireeye.com/content/dam/fireeye-www/services/pdfs/mandiant-apt1-report.pdf)
